Running large language models locally has become incredibly easy thanks to tools like **Ollama**. In this post, we'll see how to get started in just a few minutes.

## 🚀 Why use local models?

- **Privacy:** Your data never leaves your machine.
- **No Cost:** You don't pay for tokens or subscriptions.
- **No Internet:** It works completely offline once the model is downloaded.

## ⚙️ Installation

1. Download Ollama from [ollama.com](https://ollama.com).
2. Install it following the instructions for your operating system (macOS, Linux, or Windows).

## 📦 Running your first model

Once installed, open your terminal and run:

```bash
ollama run llama3
```

This command will download the model (if you don't have it) and open an interactive chat.

## 🛠️ Useful Commands

| Action | Command |
| :--- | :--- |
| List models | `ollama list` |
| Remove a model | `ollama rm <name>` |
| Update Ollama | Just download the new version |
